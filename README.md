# VLM Robot Target Selection

Language-guided robot target selection with SmolVLM-500M-Instruct and LoRA on RoboRefIt.

The complete reproducible Colab notebook, source archive, evaluation reports, and adapter artifacts are available in this repository.

## Results

- Seed 42 validation: 53/128 (41.41%) versus 32/128 pretrained.
- TestA: 31.0% adapted versus 29.0% baseline.
- TestB: 27.5% adapted versus 17.5% baseline.

See the notebook and docs for protocol and limitations.
